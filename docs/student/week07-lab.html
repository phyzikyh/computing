21  7주차 코딩 실습

이 실습은 파이썬의 핵심 자료구조인 리스트, 튜플, 딕셔너리를 활용하여 대용량 정형 데이터를 조직화하고 처리하는 과정입니다.

21.1 예제 코드

예제 1: 학생 성적 통계 분석기

scores = [88, 92, 75, 64, 98, 82, 91, 79, 85, 100]

total = sum(scores)
count = len(scores)
avg = total / count
highest = max(scores)
lowest = min(scores)

print(f"응시자: {count}명, 총점: {total}점, 평균: {avg:.2f}점")
print(f"최고점: {highest}점, 최저점: {lowest}점")
