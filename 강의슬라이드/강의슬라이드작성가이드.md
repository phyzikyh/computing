# 강의슬라이드 작성 가이드

컴퓨팅적 사고와 논리적 문제해결 · Reveal.js 슬라이드 제작 규칙

이 문서는 주차별 강의 슬라이드를 만들 때 지켜야 할 규칙을 정리한 것입니다.
새 주차 슬라이드를 만들거나 기존 슬라이드를 고칠 때 이 규칙을 따릅니다.

---

## 0. 가장 중요한 규칙 — 어떤 컴퓨터에서도 열리게

> **모든 슬라이드는 `embed-resources: true`로 렌더하여, 외부 폴더 없이 열리는 단일 HTML 파일로 만듭니다.**

- 이 옵션이 없으면 렌더된 `.html`은 옆의 `weekNN_slide_files/` 폴더에 있는
  Reveal.js·Mermaid·CSS·JS를 참조합니다. `.html` 하나만 강의실 PC로 옮기면
  그 폴더가 따라오지 않아 **깨진 채로 열립니다.**
- `embed-resources: true`를 넣으면 필요한 CSS·JS·폰트·Mermaid 스크립트가 모두
  HTML 안에 인라인됩니다(파일 약 6~7MB). USB·이메일로 `.html` 한 개만 옮겨도
  인터넷 없이, 어떤 컴퓨터에서도 정상적으로 열립니다.
- **판서(chalkboard) 플러그인은 사용하지 않습니다.** self-contained 출력과
  호환되지 않아 렌더가 실패합니다(`RevealChalkboard is not compatible with
  self-contained output`). 판서가 꼭 필요하면 그 주차만 별도로 관리합니다.

렌더 후에는 아래로 외부 참조가 0인지 반드시 확인합니다.

```bash
grep -oE '(src|href)="[^"]*"' _site/weekNN_slide.html | grep -iE '_files|http|\.js"|\.css"' | grep -viE '="data:' | sort -u
```

출력이 비어 있으면(0줄) 완전한 self-contained입니다.

## 1. 소스와 결과물

- **원본**: 이론 교재 `../강의교재/weekNN_lecture.qmd`의 내용을 바탕으로 작성합니다.
- **슬라이드 소스**: `강의슬라이드/weekNN_slide.qmd` (Quarto, Reveal.js)
- **주차별 CSS**: `강의슬라이드/weekNN-slide.css`
- **공통 템플릿 CSS**: `강의슬라이드/강의슬라이드 작성템플릿/week01-clean.css` (수정하지 않음)
- **렌더 결과**: `quarto render weekNN_slide.qmd` → `_site/weekNN_slide.html` (단일 파일)

파일 이름은 밑줄(`_`) 형식(`weekNN_slide`)을 정식으로 사용합니다.
강의실 배포·학생 공유에는 언제나 밑줄 형식의 단일 HTML을 씁니다.

분량은 50분 강의 기준 **35~40장**을 목표로 합니다(`##` 하나가 슬라이드 1장).

발표자 노트(`::: {.notes}`), 슬라이드별 배정 시간, 누적 시간은 작성하지 않습니다.
수업 시간은 전체 구성과 활동 분량으로 조절하며 슬라이드 파일에는 표시하지 않습니다.

## 2. 표준 frontmatter (복사해서 사용)

새 주차는 아래 frontmatter로 시작합니다. `WEEK`, 주차 번호, 제목만 바꿉니다.

```yaml
---
title: "이번 주차 제목"
subtitle: "컴퓨팅적 사고와 논리적 문제해결"
author: "유한대학교"
lang: ko
mermaid:
  theme: default
format:
  revealjs:
    theme: simple
    embed-resources: true        # ← 반드시 포함 (self-contained)
    self-contained-math: true
    css:
      - "강의슬라이드 작성템플릿/week01-clean.css"
      - weekNN-slide.css
    width: 1280
    height: 720
    margin: 0.05
    slide-number: c/t
    controls: true
    progress: true
    center: false
    transition: none
    incremental: false
    code-overflow: wrap
    highlight-style: github
footer: "컴퓨팅적 사고와 논리적 문제해결 · Week NN"
---
```

주차별 `weekNN-slide.css`는 기존 주차 파일을 복사한 뒤 첫 줄의 WEEK 라벨만 바꿉니다.

```css
.reveal #title-slide::after { content: "WEEK NN"; }
```

나머지 Mermaid 크기·색상 규칙은 그대로 유지합니다.

## 3. 디자인 요소 (템플릿 클래스)

### 현재 주차 범위 유지

- 슬라이드에는 해당 주차 이론과 활동만 포함합니다.
- `이후 단원에서 다룸`, `다음 주차에서 배움`, `별도 단원에서 설명`처럼 다른 주차나 미래 학습을 가리키는 문장을 넣지 않습니다.
- 현재 주차의 이해에 필요하지 않은 예고·후속 학습 안내·범위 밖의 주의사항을 추가하지 않습니다.
- 교재에 없는 확장 설명을 추가해야 할 때에는 먼저 해당 주차의 학습 목표와 직접 관련되는지 확인합니다.

파이썬 실행 결과는 `text` 블록에 수동 작성하지 않습니다. `{python}` 실행 셀을 사용하고,
렌더 시 Jupyter 커널이 생성한 출력을 표시합니다. 입력 예제는 명시적인 시연 입력값을
렌더용 숨김 셀에서 제공하여 자동 실행합니다. 코드와 출력의 설명은 두 영역 아래에 배치합니다.

`week01-clean.css`에 정의된 클래스를 조합해 화면을 구성합니다.

| 클래스 | 용도 |
|:---|:---|
| `.top-slide` | 제목을 위로 붙이는 슬라이드(목차·정리·문제) |
| `.columns` + `.column width="..%"` | 좌우 분할 배치 |
| `.box` + `.blue`/`.green`/`.orange`/`.red`/`.muted-box` | 색상 카드 |
| `.center` | 카드 안 가운데 정렬 |
| `.hero-question` | 도입 질문(파란 큰 글씨) |
| `.big-claim` | 핵심 주장 한 문장(강조 박스) |
| `.mermaid-caption` | 흐름도 아래 한 줄 설명(주차 CSS에 정의) |
| 표(마크다운 `\|`) | 비교·정리 |

**구성 흐름 권장 패턴**: 도입 질문(`hero-question`) → 개념·예시(box·표·mermaid)
→ 핵심 정리(`big-claim`). 각 절의 마지막에 blockquote(`>`)로 한 줄 요약을 답니다.

## 4. Mermaid 다이어그램 규칙

Mermaid는 브라우저에서 그려지며, 노드 텍스트가 도형보다 길면 **잘리거나 겹칩니다.**
다음을 지킵니다.

- **노드 라벨은 짧게.** 한 노드에 개념 하나(예: `추상화`, `몫 → per_booth`).
  긴 수식·설명은 노드에 넣지 말고, 아래 `::: {.mermaid-caption}` 또는 blockquote로 뺍니다.
- **가로(LR) 흐름은 노드 5개 이하.** 그보다 많으면 라벨을 더 줄이거나 세로(TD)로 바꿉니다.
- **서브그래프의 좌우 순서를 고정**하려면 보이지 않는 링크로 순서를 지정합니다.
  예: `S1 ~~~ S2 ~~~ S3` (정의 순서만으로는 역순으로 배치될 수 있음).
- 긴 순서도(TD)는 주차 CSS의 `.mermaid-tall`로 감싸 화면 높이에 맞춥니다.
- 넓은 비교 흐름도는 `.mermaid-wide`로 감쌉니다.
- 색상은 교재와 통일합니다(파랑 `#dbeafe/2563eb`, 보라 `#ede9fe/7c3aed`,
  초록 `#dcfce7/16a34a`, 주황 `#fef3c7/d97706`, 빨강 `#fee2e2/dc2626`).

의사코드·`text` 코드블록은 `::: {.pseudocode}`로 감싸 왼쪽 정렬로 또렷하게 보여 줍니다.

## 5. 렌더 · 검증 절차

### Windows 미리보기

같은 슬라이드에 대해 편집기의 Preview와 터미널의 `quarto preview`를 동시에 실행하지 않습니다.
두 프로세스가 같은 임시 `_files` 리소스를 생성·정리하면 `Could not fetch resource`와 404가 발생할 수 있습니다.
이 경우 해당 슬라이드의 미리보기를 모두 종료한 뒤 하나만 다시 실행합니다.
`Output created`만으로 성공을 판단하지 말고 리소스 누락 경고가 없는지 확인합니다.

`강의슬라이드` 폴더에서 `quarto preview week04_slide.qmd --profile preview`를 실행합니다.
다른 주차는 파일명만 바꿉니다. `_quarto-preview.yml`은 출력 위치를 현재 폴더로 지정하여,
HTML을 `_site`로 이동할 때 발생할 수 있는 Windows 파일 잠금 오류(os error 32)를 피합니다.
미리보기 종료는 해당 터미널에서 Ctrl+C를 누릅니다.
미리보기 HTML은 원본 옆에 생성됩니다. 아래 일반 렌더 명령은 기존처럼 `_site`에 최종본을 만듭니다.

```bash
cd 강의슬라이드
quarto render weekNN_slide.qmd
```

렌더 후 확인:

1. **self-contained 확인** — 위 0장의 `grep` 명령 출력이 0줄인지 확인합니다.
2. **브라우저 확인** — `_site/weekNN_slide.html`을 브라우저로 열어
   - 제목 슬라이드·표·색상 카드가 정상 렌더되는지
   - 모든 Mermaid 다이어그램의 글자가 도형 밖으로 잘리거나 겹치지 않는지
   - 다이어그램 순서가 의도한 좌→우/위→아래인지
   를 확인합니다. (창을 최대화한 정상 상태에서 확인합니다.)

문제가 있으면 4장 규칙에 따라 라벨을 줄이거나 캡션으로 빼고 다시 렌더합니다.
