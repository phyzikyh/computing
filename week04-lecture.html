11  이론

11.1 변수: 메모리 공간을 가리키는 이름표

컴퓨터 프로그래밍에서 변수(Variable)란 데이터를 저장하기 위해 할당된 컴퓨터 주기억장치(RAM)의 메모리 공간에 붙이는 이름입니다.

파이썬의 객체 참조(Object Reference) 메커니즘

C나 Java 같은 정적 타입 언어에서 변수는 데이터를 직접 담는 ’고정된 상자’에 가깝지만, 파이썬에서 모든 것은 객체(Object)이며 변수는 객체가 위치한 메모리 주소를 가리키는 ‘포인터/이름표(Tag)’ 역할을 합니다.

score = 95

만약 score = score + 5를 실행하면 기존 \(95\)가 \(100\)으로 덮어써지는 것이 아니라, 메모리에 새로운 \(100\) 객체가 생성되고 score 이름표가 새로운 객체를 가리키게 됩니다.

변수 명명 규칙 (Naming Conventions)

좋은 변수 이름은 코드의 가독성과 유지보수성을 극적으로 높여줍니다.

구분 올바른 규칙 및 권장 사항 잘못된 예시 (문법 오류 / 지양)
문자 구성 영문자(대소문자 구분), 숫자, 밑줄(_) 사용 가능 1st_score (숫자로 시작 불가)
예약어 제한 파이썬 키워드(if, for, class 등)는 변수명 불가 for = 10 (문법 에러 발생)
표기법 (스네이크 케이스) 단어와 단어 사이를 밑줄로 연결 (user_age, total_price) userage (가독성 저하)
의미 전달 변수에 담긴 데이터의 목적이 명확히 드러나야 함 a = 5000 대신 hourly_wage = 5000

11.2 파이썬의 4대 기본 자료형 (Data Types)

파이썬은 변수에 값을 대입하는 순간 인터프리터가 데이터의 형식을 자동으로 판별하는 동적 타이핑(Dynamic Typing)을 지원합니다.

자료형 키워드 표현 예시 특징 및 용도
정수형 int count = 15, step = -3 소수점이 없는 정수, 자릿수 제한 없이 무한대 표현 가능
실수형 float pi = 3.141592, height = 175.5 소수점을 포함하는 실수 (부동소수점 표현)
문자열형 str name = "신기홍", dept = 'AI학부' 큰따옴표(") 또는 작은따옴표(')로 둘러싸인 텍스트
불리언형 bool is_valid = True, has_passed = False 참(True) 또는 거짓(False)의 2가지 논리 상태 
# type() 함수를 사용한 자료형 확인
age = 20
rate = 4.5
subject = "컴퓨팅적사고"
is_registered = True

print(type(age))            # <class 'int'>
print(type(rate))           # <class 'float'>
print(type(subject))        # <class 'str'>
print(type(is_registered))  # <class 'bool'>

11.3 표준 입출력과 자료형 변환 (Type Casting)

input() 함수의 특성과 문자열 반환

키보드로부터 사용자 입력을 받는 input() 함수는 사용자가 숫자를 입력하더라도 항상 문자열(str) 형식으로 수신합니다. 따라서 산술 연산을 수행하기 위해서는 반드시 명시적 형변환(Type Casting)을 거쳐야 합니다.

# [주의] 형변환을 하지 않았을 때 발생하는 흔한 실수
str_num1 = "10"
str_num2 = "20"
print(str_num1 + str_num2)  # 출력: 1020 (문자열 이어붙이기)

# [올바른 처리] int() 형변환 적용
int_num1 = int(str_num1)
int_num2 = int(str_num2)
print(int_num1 + int_num2)  # 출력: 30 (정수 덧셈)

11.4 파이썬 연산자의 종류와 우선순위

1. 산술 연산자 (Arithmetic Operators)

연산자 기능 설명 예시 식 계산 결과
+ 덧셈 7 + 3 10
- 뺄셈 7 - 3 4
* 곱셈 7 * 3 21
/ 나눗셈 (결과는 항상 float) 7 / 2 3.5
// 몫 연산자 (소수점 이하 버림) 7 // 2 3
% 나머지 연산자 (Modulo) 7 % 2 1
** 거듭제곱 2 ** 3 8

2. 관계 및 비교 연산자 (Comparison Operators)

연산 결과는 항상 bool 값(True 또는 False)이 도출됩니다.

  • == (같다), != (다르다)
  • > (초과), >= (이상), < (미만), <= (이하)

3. 논리 연산자 (Logical Operators)

  • and: 양쪽 조건이 모두 참일 때만 True
  • or: 양쪽 조건 중 하나라도 참이면 True
  • not: 조건의 참/거짓 상태를 반전

11.5 실전 응용 예제 2선

예제 1: 아르바이트 주급 계산기

시급, 근무 시간, 주휴수당(주 15시간 이상 근무 시 지급)을 반영하여 최종 급여를 계산합니다.

# 1. 입력 데이터 정의
hourly_wage = 10030   # 2026년 최저시급 (원)
work_hours = 20       # 주간 근무 시간

# 2. 기본급 계산
base_pay = hourly_wage * work_hours

# 3. 주휴수당 자격 검사 (15시간 이상 여부)
eligible_holiday_pay = work_hours >= 15

# 주휴수당 (근무시간 / 40 * 8 * 시급)
holiday_pay = int((work_hours / 40) * 8 * hourly_wage) if eligible_holiday_pay else 0
total_pay = base_pay + holiday_pay

print(f"기본 급여: {base_pay:,}원")
print(f"주휴수당 지급 대상 여부: {eligible_holiday_pay}")
print(f"주휴수당: {holiday_pay:,}원")
print(f"최종 총 주급: {total_pay:,}원")

예제 2: BMI 체질량 지수 계산기

신장(\(\text{cm}\))과 체중(\(\text{kg}\))을 바탕으로 비만도를 판정합니다.

\[\text{BMI} = \frac{\text{체중}(\text{kg})}{\left(\frac{\text{신장}(\text{cm})}{100}\right)^2}\]

height_cm = 175.0
weight_kg = 68.5

# 신장을 미터(m) 단위로 변환
height_m = height_cm / 100

# BMI 계산 (거듭제곱 연산자 ** 활용)
bmi = weight_kg / (height_m ** 2)

print(f"신장: {height_cm}cm, 체중: {weight_kg}kg")
print(f"계산된 BMI 지수: {bmi:.2f}")
print(f"정상 체중 범위(18.5 <= BMI < 23) 여부: {18.5 <= bmi < 23}")
