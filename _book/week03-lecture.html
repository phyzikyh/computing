7  추상화와 알고리즘 표현

학습 목표

  1. 복잡성을 통제하고 본질에 집중하는 추상화(Abstraction)의 원리와 정보 은닉(Information Hiding) 개념을 이해합니다.
  2. 알고리즘을 표현하는 3가지 방식(자연어, 의사코드, 순서도)의 장단점을 비교하고 올바른 작성법을 익힙니다.
  3. 모든 컴퓨터 프로그램의 3대 기본 제어 구조인 순차 구조 · 선택 구조 · 반복 구조를 순서도로 시각화합니다.
  4. 스마트 냉장고 유통기한 관리 등 실세계 시나리오를 바탕으로 의사코드와 순서도를 직접 설계하고 파이썬으로 구현합니다.

7.1 복잡성을 제어하는 도구: 추상화 (Abstraction)

컴퓨터 과학 역사상 가장 위대한 튜링상 수상자 중 한 명인 에츠허르 데이크스트라(Edsger W. Dijkstra)는 “추상화의 목적은 모호해지는 것이 아니라, 정확하게 생각할 수 있는 새로운 의미론적 단계를 창조하는 것”이라고 역설했습니다(Dijkstra 1972년).

추상화(Abstraction)란 문제 해결에 불필요한 세부 사항(Noise)을 의도적으로 감추고, 본질적인 핵심 속성과 기능(Signal)만을 추출하여 단순한 모델로 만드는 지적 작업입니다(Wing 2008년; Sorva 2013년).

블랙박스(Black Box) 모델과 정보 은닉

추상화의 가장 대표적인 형태가 바로 블랙박스 모델(Black Box Model)입니다(Abelson 기타 1996년). 사용자는 내부의 복잡한 기계적 메커니즘을 몰라도, 입력(Input)과 출력(Output), 그리고 인터페이스(Interface)만 알면 기능을 완벽하게 활용할 수 있습니다.

  • 자동차 운전: 운전자는 엔진의 연료 분사 타이밍이나 변속기 기어비를 몰라도, 가속 페달과 핸들(인터페이스)만으로 자동차를 제어합니다.
  • 파이썬 내장 함수 sum(): 사용자는 내부적으로 C 언어로 어떻게 메모리를 순회하며 덧셈하는지 몰라도, sum([10, 20, 30])을 호출하면 정확히 \(60\)을 얻습니다.

실전 시나리오: 지하철 노선도와 지도 내비게이션의 추상화

실제 지리 정보를 담은 위성 사진과 지하철 노선도를 비교해 보면 추상화의 강력함을 즉시 체감할 수 있습니다.

비교 항목 위성 사진 지도 (구체적 표현) 지하철 노선도 (추상화된 표현)
포함된 정보 실제 지형, 산과 강, 도로의 곡률, 건물 높이 역과 역 사이의 연결 관계, 환승역, 소요 시간
장점 실제 지리적 위치 파악에 유리 이동 경로와 환승 계획을 한눈에 파악하기에 압도적으로 유리
컴퓨터 모델 대용량 래스터 이미지 파일 그래프(Graph) 자료구조 (노드와 간선)

추상화의 핵심 가치: 모든 정보를 다 담으려 하면 복잡성 때문에 문제를 풀 수 없습니다. 해결하려는 목적에 꼭 필요한 정보만 남기는 것이 추상화의 정수입니다.

7.2 알고리즘을 표현하는 3가지 방법

문제를 해결하기 위한 논리적 절차인 알고리즘(Algorithm)은 다음 3가지 방법으로 표현할 수 있습니다(Cormen 기타 2022년; Sedgewick 기타 2016년).

표현 방식 주요 장점 한계 및 단점 적합한 활용 상황
자연어 누구나 쉽게 읽고 이해할 수 있음 문장의 모호성(Ambiguity)으로 인해 컴퓨터 로직으로 직결되기 어려움 초기 아이디어 스케치, 기획 회의
의사코드 프로그래밍 언어 문법에 얽매이지 않고 논리 골격에만 집중 가능 표준화된 문법 규칙이 없어 작성자마다 표현이 조금씩 다를 수 있음 복잡한 알고리즘 논문 발표, 팀 내 로직 검토
순서도 제어 흐름(조건 분기, 루프)이 시각적으로 명확하게 드러남 로직이 매우 길어지면 도면이 복잡해져 관리가 어려움 알고리즘 교육, 업무 프로세스 명세화

7.3 순서도(Flowchart)의 기본 기호와 3대 제어 구조

순서도는 국제표준화기구(ISO)와 ANSI 표준 규격에 정의된 도형을 사용합니다.

표준 순서도 기호

기호 명칭 도형 모양 기능 및 역할
단말 (Terminal) 타원 / 둥근 사각형 알고리즘의 시작(Start)과 종료(End)를 나타냄
준비 / 초기화 (Preparation) 육각형 변수의 선언 및 초기값 설정
처리 (Process) 직사각형 산술 연산, 데이터 할당, 값의 변경
판단 / 조건 (Decision) 마름모 조건식의 참(True) / 거짓(False)에 따라 실행 경로를 분기
입출력 (Input/Output) 평행사변형 외부 데이터 입력 받기, 화면에 결과 출력하기
흐름선 (Flowline) 화살표 (\(\rightarrow\)) 제어의 이동 방향 및 실행 순서 표시

모든 프로그램을 구성하는 3대 기본 제어 구조

1966년 컴퓨터과학자 보엠(Böhm)과 자코피니(Jacopini)는 구조적 프로그래밍 정리(Structured Program Theorem)를 통해, 아무리 복잡한 프로그램이라도 오직 순차, 선택, 반복의 3가지 기본 제어 구조만으로 완벽하게 표현할 수 있음을 수학적으로 증명하였습니다.

7.4 실전 종합 사례: 스마트 냉장고 유통기한 판별 시스템

1. 문제 시나리오

스마트 냉장고에 보관 중인 식자재들의 남은 유통기한(일수) 리스트가 주어졌을 때, 유통기한이 지난 상품(음수)은 ‘폐기 알림’, 3일 이하로 남은 상품은 ‘소비 권장 알림’, 그 외에는 ‘보관 양호’로 자동 분류하는 알고리즘을 설계합니다.

2. 의사코드 (Pseudocode)

알고리즘: FoodExpirationManager
입력: 식자재 남은 일수 목록 days_left

1. discard_count ← 0
2. urgent_count ← 0
3. safe_count ← 0

4. days_left의 각 항목(d)에 대해 순차 반복:
     만약 d < 0 이면:
         discard_count ← discard_count + 1
     그렇지 않고 만약 d <= 3 이면:
         urgent_count ← urgent_count + 1
     그렇지 않으면:
         safe_count ← safe_count + 1

5. 폐기 수량(discard_count), 긴급 수량(urgent_count), 안전 수량(safe_count) 출력

3. 순서도 (Flowchart)

4. 파이썬 코드 구현

# 스마트 냉장고에 보관된 식자재들의 남은 유통기한 일수
# 음수: 기한 경과, 0: 오늘까지, 양수: 남은 일수
food_days = [5, -2, 0, 12, 2, -1, 7, 1]

discard_count = 0
urgent_count = 0
safe_count = 0

for d in food_days:
    if d < 0:
        discard_count += 1
    elif d <= 3:
        urgent_count += 1
    else:
        safe_count += 1

print("--- 스마트 냉장고 재고 관리 리포트 ---")
print(f"즉시 폐기 대상: {discard_count}개")
print(f"소비 권장(임박): {urgent_count}개")
print(f"안전 보관 중: {safe_count}개")

요약 및 핵심 정리

  1. 추상화(Abstraction)는 문제 해결 목적에 맞게 핵심적인 정보와 기능만을 추출하고 불필요한 세부 구현을 감추는(정보 은닉) 지적 도구입니다.
  2. 알고리즘 표현 방법에는 자연어, 의사코드, 순서도가 있으며, 개발 단계에 맞추어 적절한 표현 방식을 선택합니다.
  3. 모든 알고리즘은 순차(Sequence), 선택(Selection), 반복(Iteration)의 3대 기본 제어 구조의 조합만으로 설계할 수 있습니다.
