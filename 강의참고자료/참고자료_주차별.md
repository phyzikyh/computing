# 주차별 강의작성 참고자료

이 문서는 학생용 Quarto Book에 표시하지 않고 강의자료 작성·수정 시 출처를 확인하기 위해 별도로 관리한다. 동일 문헌이 여러 주차에 사용된 경우 해당 주차마다 다시 기록하였다.

## 1주차: 컴퓨팅 사고와 디지털 문제해결

- 컴퓨팅 사고의 역사와 정의
- 문제 분해, 패턴 인식, 추상화, 알고리즘의 관계
- 컴퓨터 시스템과 문제해결 과정
- 알고리즘이 갖추어야 할 조건

## 관리 원칙

- 학생용 강의자료 본문에는 인용 키나 참고문헌 목록을 표시하지 않는다.
- 새로운 내용을 추가할 때 실제로 확인한 자료를 해당 주차에 기록한다.
- 웹 자료는 문서 제목, 기관명, URL을 함께 기록한다.
- 논문과 도서는 저자, 연도, 제목, 출판정보, DOI를 가능한 범위에서 기록한다.
- 교재에서 가져온 것은 설명 항목의 범위이며, 문장·도표·예시는 새로 작성한다.
