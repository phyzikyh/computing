코딩실습

예제 1. 한 줄 출력

print("대학 축제 준비를 시작합니다.")
대학 축제 준비를 시작합니다.

print()의 괄호 안에 문자열을 넣으면 따옴표를 제외한 내용이 화면에 출력된다.

예제 2. 여러 값과 자료형 출력

event_name = "가을 축제"
visitors = 240
open_rate = 0.85
is_open = True

print(event_name, type(event_name))
print(visitors, type(visitors))
print(open_rate, type(open_rate))
print(is_open, type(is_open))
가을 축제 <class 'str'>
240 <class 'int'>
0.85 <class 'float'>
True <class 'bool'>

str, int, float, bool은 각각 문자열, 정수, 실수, 불리언을 뜻한다. type()은 값의 자료형을 확인한다.

예제 3. 숫자 계산과 산술 연산자

print(18 + 7)   # 기존 부스와 추가 부스의 합
print(18 - 7)   # 아직 점검하지 않은 부스 수
print(18 * 7)   # 부스 18곳에 생수 7병씩 배부
print(18 / 7)   # 부스를 안전요원 7명이 나누어 담당
print(18 // 7)  # 안전요원 한 명이 맡는 부스의 몫
print(18 % 7)   # 균등하게 배정하고 남는 부스
print(2 ** 4)   # 구역을 단계적으로 둘씩 나눌 때의 수
25
11
126
2.5714285714285716
2
4
16

/는 나눗셈 결과, //는 몫, %는 나머지, **는 거듭제곱을 구한다.

예제 4. 변수에 값 저장

visitors = 240
booths = 6
print(visitors)
print(booths)

visitors = 252
print(visitors)
240
6
252

변수 이름에는 문자, 숫자, 밑줄을 사용할 수 있지만 숫자로 시작할 수 없다. 공백이나 하이픈 대신 total_students처럼 밑줄을 사용한다. 같은 변수에 새 값을 대입하면 이후에는 새 값이 사용된다.

예제 5. 변수와 문자열 연산

event = "축제"
place = "광장"
print(event + " 장소: " + place)
print("입장 안내 " * 3)
축제 장소: 광장
입장 안내 입장 안내 입장 안내

문자열끼리 +로 연결할 수 있고 문자열에 정수를 *하면 같은 문자열이 반복된다.

예제 6. 입력과 자료형 변환

visitors_text = input("예상 방문객 수: ")
booths_text = input("부스 수: ")

visitors = int(visitors_text)
booths = int(booths_text)
visitors_per_booth = visitors / booths
print("부스당 예상 방문객:", visitors_per_booth)
예상 방문객 수: 240
부스 수: 6
부스당 예상 방문객: 40.0

input()의 결과는 문자열이다. 숫자 계산 전에는 int()나 float()로 변환해야 한다. 반대로 숫자를 문자열로 바꿀 때는 str()을 사용한다.

예제 7. 계산과 f-string 출력

total_budget = 900000
equipment = 320000
promotion = 180000
remaining = total_budget - equipment - promotion
print(f"총예산: {total_budget:,}원")
print(f"남은 예산: {remaining:,}원")
총예산: 900,000원
남은 예산: 400,000원

문자열 앞에 f를 붙이면 중괄호 안의 변수와 계산식을 문자열에 넣을 수 있다. :,는 큰 숫자에 천 단위 쉼표를 표시한다.

예제 8. 순차 처리 표현

print("1. 참가 부스 신청 확인")
print("2. 구역별 부스 수 계산")
print("3. 부스 배치 결과 출력")
1. 참가 부스 신청 확인
2. 구역별 부스 수 계산
3. 부스 배치 결과 출력

파이썬은 기본적으로 위에서 아래로 실행하므로 출력 순서 자체가 작업 순서를 표현한다.

예제 9. 반복되는 구조에서 패턴 찾기

day1_visitors = 120
day2_visitors = 150
print("1일차 1시간당 평균:", day1_visitors / 3)
print("2일차 1시간당 평균:", day2_visitors / 3)
1일차 1시간당 평균: 40.0
2일차 1시간당 평균: 50.0

방문객 수는 달라도 방문객 수 / 운영 시간이라는 계산 패턴은 같다. 이후 함수를 배우면 이 공통 계산을 한 번만 작성할 수 있다.

예제 10. 오류 읽고 수정하기

total_visitors = 80
# print(total_visiters)  # NameError: total_visiters가 정의되지 않음
# print("방문객: " + total_visitors)  # TypeError: 문자열과 정수를 바로 연결함
# int("여든")  # ValueError: 숫자로 바꿀 수 없는 문자열
print(total_visitors)
80

NameError는 정의되지 않은 이름, TypeError는 맞지 않는 자료형의 연산, ValueError는 값 변환 실패를 나타낸다. print("방문객:", total_visitors) 또는 print(f"방문객: {total_visitors}")처럼 자료형에 맞게 고친다.

문제 10. 미니 프로그램 만들기

다음 조건을 모두 만족하는 축제 간식 배분 프로그램을 작성한다.

  1. input()으로 전체 간식 수와 축제 부스 수를 입력받고 정수로 변환한다.
  2. 부스당 수량과 남는 수량을 각각 의미 있는 변수에 저장한다.
  3. 부스당 수량은 //, 남는 수량은 %로 계산한다.
  4. 프로그램 제목, 두 입력값, 두 계산 결과를 f-string으로 출력한다.
  5. 입력·처리·출력 부분을 구분하는 주석을 세 개 이상 작성한다.
