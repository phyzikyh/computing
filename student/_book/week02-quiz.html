5  2주차 연습문제

1. 조지 포야(George Pólya)가 제시한 문제해결 4단계의 올바른 순서는?

① 계획 수립 → 문제 이해 → 계획 실행 → 반성
② 문제 이해 → 계획 수립 → 계획 실행 → 반성
③ 계획 실행 → 문제 이해 → 계획 수립 → 반성
④ 문제 이해 → 계획 실행 → 계획 수립 → 반성

2. 문제 분해(Decomposition)의 주된 목적이 아닌 것은?

① 복잡하고 큰 문제를 해결 가능한 작은 단위로 축소한다
② 여러 사람이 역할을 나누어 협업하기 쉽게 만든다
③ 컴퓨터 메모리 사용량을 강제로 0으로 만든다
④ 각 모듈의 오류를 독립적으로 디버깅하기 쉽게 한다

3. 시스템의 최상위 목표에서 시작하여 점차 하위 세부 기능으로 쪼개어 나가는 접근법은?

① 상향식 접근법 (Bottom-Up)
② 하향식 접근법 (Top-Down)
③ 무작위 접근법 (Randomized)
④ 역방향 접근법 (Backtracking)

4. 소프트웨어 모듈화에서 “바람직한 모듈의 특성”으로 옳은 것은?

① 높은 결합도, 낮은 응집도
② 낮은 결합도, 높은 응집도
③ 높은 결합도, 높은 응집도
④ 낮은 결합도, 낮은 응집도

5. 다음 중 “시간적 패턴(Temporal Pattern)”에 해당하는 사례는?

① 학생들의 이름, 학번, 전공 데이터 목록
② 주말 야간마다 OTT 서비스 영화 시청량이 정기적으로 급증하는 현상
③ 지하철 노선도의 역과 환승 정보
④ 사칙연산의 연산자 우선순위

6. 데이터 속에서 발견된 규칙을 바탕으로 “만약 비가 오면 우산을 챙긴다”와 같이 프로그래밍할 때 사용하는 제어구조는?

① 반복문 (for, while)
② 조건문 (if-else)
③ 입출력 함수 (print)
④ 주석문 (#)

7. 동일한 형식의 데이터 레코드가 수천 개 나열되어 있을 때, 이를 일괄 처리하기에 가장 적합한 프로그래밍 요소는?

① 산술 연산자
② 반복문 (루프)
③ 변수 재선언
④ pass 키워드

8. 무인 매장 결제 시스템을 기능별로 분해할 때, ’금액 계산 모듈’의 세부 하위 기능으로 적절하지 않은 것은?

① 상품 단가 합산
② 1+1 행사 할인 적용
③ 신용카드 IC칩 물리적 통신 승인
④ 멤버십 포인트 차감

9. 기상 데이터에서 “강수확률이 60% 이상일 때 우산이 필요하다”는 판단을 내릴 때, 60%와 같은 기준값을 무엇이라 부르는가?

① 임계값 (Threshold)
② 가중치 (Weight)
③ 바이어스 (Bias)
④ 주파수 (Frequency)

10. 다음 중 “상향식(Bottom-Up)” 접근법의 특징으로 옳은 것은?

① 전체 시스템 아키텍처를 가장 먼저 기획한다
② 이미 검증된 작은 기초 단위 함수들을 먼저 만든 후 이를 결합하여 시스템을 완성한다
③ 비즈니스 요구사항 명세서만 작성하고 코딩은 하지 않는다
④ 세부 기능을 전혀 분해하지 않고 하나의 코드로 작성한다

11. 다음 파이썬 리스트에서 len(rain_data)가 반환하는 값은?

rain_data = [10, 80, 90, 20, 30, 70, 0]

① 6
② 7
③ 8
④ 90

12. 복잡한 문제를 분해할 때 가장 주의해야 할 점은?

① 쪼개진 부분 문제들이 서로 너무 강하게 얽혀 독립적으로 풀 수 없게 되는 것
② 부분 문제의 수가 짝수가 되지 않는 것
③ 파이썬 파일의 용량이 커지는 것
④ 변수명을 영어로 작성하는 것

13. 데이터 분석에서 “두 변수가 함께 증가하거나 감소하는 경향”을 나타내는 패턴은?

① 주기성
② 상관관계 (Correlation)
③ 분산
④ 결측치

14. 다음 중 프로그래밍의 “함수(def)”가 문제 해결에 기여하는 바는?

① 반복되는 공통 패턴 로직을 하나의 이름으로 묶어 재사용 가능하게 한다
② 컴퓨터의 전력 소모를 0으로 줄여준다
③ 조건문의 실행을 금지한다
④ 모든 변수를 상수로 변환한다

15. 아래 코드의 출력 결과로 옳은 것은?

probs = [20, 70, 40, 85]
count = 0
for p in probs:
    if p >= 60:
        count += 1
print(count)

① 1
② 2
③ 3
④ 4

16. 문제 분해 시 “독립적인 부분 문제”를 만드는 것이 중요한 주된 이유는?

① 각 부분을 병렬로 개발하거나 독립적으로 테스트할 수 있기 때문
② 컴퓨터의 CPU 개수가 무한정 늘어나기 때문
③ 변수 선언을 생략할 수 있기 때문
④ 파이썬 인터프리터의 문법 오류가 사라지기 때문

17. 쇼핑몰 고객 로그에서 “장바구니에 상품을 담은 후 1시간 이내 결제율이 80%”임을 밝혀낸 것은 컴퓨팅 사고의 어느 단계인가?

① 문제 분해
② 패턴 인식
③ 하드웨어 최적화
④ 컴파일

18. 에츠허르 데이크스트라가 강조한 “관심사의 분리(Separation of Concerns)”와 가장 밀접한 컴퓨팅 사고 개념은?

① 문제 분해 (Decomposition)
② 무한 루프 (Infinite Loop)
③ 정적 타이핑
④ 하드웨어 가속

19. 다음 중 패턴 인식의 결과물을 컴퓨터 코드로 구현할 때 올바른 매핑은?

① 반복되는 계산 작업 \(\rightarrow\) 반복문(for/while)
② 상황별 분기 규칙 \(\rightarrow\) 조건문(if)
③ 자주 쓰이는 공통 연산 \(\rightarrow\) 함수(def)
④ ①, ②, ③ 모두 옳다

20. 조지 포야의 4단계 중 “도출된 답을 검토하고 다른 문제에 적용 가능한지 일반화하는 단계”는?

① 문제 이해
② 계획 수립
③ 계획 실행
④ 반성 및 검토 (Looking Back)
