# 자료구조를 활용한 데이터 처리 — 참고문헌

1. Python Software Foundation. *Data Structures* (리스트, 튜플, 딕셔너리). [공식 문서](https://docs.python.org/3/tutorial/datastructures.html)
2. Python Software Foundation. *Built-in Types — Sequence Types, Mapping Types*. [공식 문서](https://docs.python.org/3/library/stdtypes.html)
3. Python Software Foundation. *copy — Shallow and deep copy operations*. [공식 문서](https://docs.python.org/3/library/copy.html)
4. Python Software Foundation. *Modules* (`import`, `__name__`). [공식 문서](https://docs.python.org/3/tutorial/modules.html)
5. Python Software Foundation. *math*, *random*, *time* 모듈. [math](https://docs.python.org/3/library/math.html) · [random](https://docs.python.org/3/library/random.html) · [time](https://docs.python.org/3/library/time.html)

---

**본문에서 활용한 자료**: 리스트·튜플·딕셔너리의 조작 방법, 가변 객체의 별칭과 복사, 모듈의 불러오기와 `__name__`, `math`·`random`·`time` 모듈의 함수에 관한 설명은 Python Software Foundation의 공식 문서를 대학 교양수업 수준에 맞게 정리하였습니다.

**출처 활용 안내**: 부스 매출, 메뉴 가격표, 주문 목록, 축제 본부 좌표, 생수 포장 사례는 자료구조와 모듈 개념을 설명하기 위해 구성한 교육용 예시이며, 실제 행사 자료가 아닙니다.
