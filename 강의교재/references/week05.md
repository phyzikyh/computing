# 선택 구조를 이용한 판단 — 참고문헌

1. Python Software Foundation. *More Control Flow Tools* (if, elif, else, 함수 정의). [공식 문서](https://docs.python.org/3/tutorial/controlflow.html)
2. Python Software Foundation. *Built-in Types — Comparisons, Boolean Operations*. [공식 문서](https://docs.python.org/3/library/stdtypes.html#comparisons)
3. Dijkstra, E. W. (1972). The humble programmer. *Communications of the ACM, 15*(10), 859–866. [DOI](https://doi.org/10.1145/355604.361591)
4. Resnick, M., et al. (2009). Scratch: Programming for all. *Communications of the ACM, 52*(11), 60–67. [DOI](https://doi.org/10.1145/1592761.1592779)

---

**본문에서 활용한 자료**: 비교·논리 연산, 조건문(`if`·`elif`·`else`), 단락 평가, 함수 정의와 호출에 관한 설명은 Python Software Foundation의 공식 문서를 대학 교양수업 수준에 맞게 정리하였습니다. 선택 구조를 구조적 제어의 한 요소로 보는 관점은 Dijkstra(1972)를, 초보 학습자에게 조건 분기를 소개하는 방식은 Resnick 외(2009)를 참고하였습니다.

**출처 활용 안내**: 놀이기구 탑승 기준, 입장료 구간, 회원·성인 결정표, 나이 입력 검증 사례는 선택 구조와 함수 개념을 설명하기 위해 구성한 교육용 예시이며, 특정 시설의 실제 운영 규정이 아닙니다.
