# 컴퓨팅적 사고 기반 문제해결 종합 — 참고문헌

1. Pólya, G. (1945). *How to Solve It: A New Aspect of Mathematical Method*. Princeton University Press.
2. Wing, J. M. (2006). Computational thinking. *Communications of the ACM, 49*(3), 33–35. [DOI](https://doi.org/10.1145/1118178.1118215)
3. Python Software Foundation. *More Control Flow Tools* (조건문, 반복문, 함수 정의). [공식 문서](https://docs.python.org/3/tutorial/controlflow.html)
4. Python Software Foundation. *Data Structures* (리스트, 튜플, 딕셔너리, 정렬). [공식 문서](https://docs.python.org/3/tutorial/datastructures.html)

---

**본문에서 활용한 자료**: 문제를 이해하고 계획을 세워 실행한 뒤 되돌아본다는 문제 해결의 단계는 Pólya(1945)의 관점을 참고하였습니다. 조건문, 반복문, 함수, 자료구조의 문법은 Python Software Foundation의 공식 문서를 기준으로 확인하였습니다.

**출처 활용 안내**: 행사 참가비의 구간과 금액, 부스 판매 기록, 공유 공간의 크기, 신청자의 이름과 전화번호, 테스트 표는 문제 해결 과정을 설명하기 위해 구성한 교육용 가상 자료이며, 실제 행사의 규정이나 매출, 실존 인물의 정보가 아닙니다.
