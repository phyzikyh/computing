# 반복 구조를 이용한 자동화 — 참고문헌

1. Python Software Foundation. *More Control Flow Tools* (`for`, `range`, `break`, `continue`, 함수). [공식 문서](https://docs.python.org/3/tutorial/controlflow.html)
2. Python Software Foundation. *Built-in Functions — range*. [공식 문서](https://docs.python.org/3/library/functions.html#func-range)
3. Wing, J. M. (2006). Computational thinking. *Communications of the ACM, 49*(3), 33–35. [DOI](https://doi.org/10.1145/1118178.1118215)
4. Denning, P. J. (2009). Beyond computational thinking. *Communications of the ACM, 52*(6), 28–30. [DOI](https://doi.org/10.1145/1516046.1516054)

---

**본문에서 활용한 자료**: `for`·`while`·`range`·`break`·`continue`, 반복을 함수로 묶는 방법에 관한 설명은 Python Software Foundation의 공식 문서를 대학 교양수업 수준에 맞게 정리하였습니다. 반복을 통한 자동화가 컴퓨팅 사고의 기본 도구라는 관점은 Wing(2006)과 Denning(2009)을 참고하였습니다.

**출처 활용 안내**: 부스 정산, 매출 목록, 저축 목표 사례와 누산·계수·최댓값·탐색 예제는 반복 구조를 설명하기 위해 구성한 교육용 예시이며, 특정 행사의 실제 자료가 아닙니다.
