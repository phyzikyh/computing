# 컴퓨팅적사고와논리적문제해결 강의 작성 기준

## 1. 강의 구성의 기본 방향

이 과목은 1주차부터 8주차까지 《난생처음 컴퓨팅 사고 with 파이썬》의 1장부터 14장까지 다루고, 9주차부터 데이터 분석과 인공지능으로 넘어간다.

교재의 문장, 도표, 그림, 예제 코드를 그대로 옮기지 않는다. 다만 교재에서 설명하는 개념과 기술 항목은 빠짐없이 설명한다. 설명 순서와 사례, 데이터, 코드, 실습 문제는 새로 설계하고 교재에 없는 보충 내용을 추가한다.

강의자료는 다음 원칙을 따른다.

- 교재의 개념 항목을 모두 포함한다.
- 교재의 기존 예시는 사용하지 않고 새로운 사례로 설명한다.
- 현실 문제, 알고리즘, 코드가 하나의 흐름으로 연결되게 한다.
- 파이썬은 2주차부터 시작한다.
- 2주차는 짧은 순차 코드와 파이썬 기초를 충분히 실습한다.
- 조건문, 반복문처럼 아직 배우지 않은 문법은 완성 코드를 먼저 암기시키지 않는다.
- 각 주차는 예제 코드와 단계별 실습을 충분히 포함한다.
- 강의 이론 파일인 `weekXX-lecture.qmd`의 읽을 수 있는 본문은 3,000자 이상 작성한다.
- 퀴즈와 실습 파일에는 글자 수 기준을 적용하지 않는다.
- `학습목표`, `이 장을 마치면`, `배울 내용`, `다음 주차로 연결하기`와 같은 메타 섹션을 작성하지 않는다.
- 짧은 문제 상황이나 구체적인 사례로 본문을 시작한다.
- Mermaid, 표, 실행 결과, 코드 추적표를 필요한 위치에 사용한다.
- 참고문헌은 본문에서 실제로 인용한 자료만 출력한다.

## 2. 주차별 교재 내용 배치

| 주차 | 강의계획서 주제 | 교재 내용 |
|---|---|---|
| 1주차 | 컴퓨팅 사고와 디지털 문제해결 | 1장 전반 |
| 2주차 | 문제 분해와 패턴 인식 | 1장 문제 분해·패턴 인식 + 3장 파이썬 기초 |
| 3주차 | 추상화와 알고리즘 표현 | 1장 일반화·알고리즘 + 2장 전체 + 3~4장 일부 |
| 4주차 | 파이썬과 데이터 표현 | 3장 잔여 + 4장 + 5장 산술 연산 |
| 5주차 | 선택 구조를 이용한 판단 | 5장 비교·논리 연산 + 6장 + 함수 입문 |
| 6주차 | 반복 구조를 이용한 자동화 | 7장 + 10~11장 함수 활용 |
| 7주차 | 자료구조를 활용한 데이터 처리 | 8장 + 9장 + 12장 모듈 |
| 8주차 | 컴퓨팅 사고 기반 문제해결 종합 | 13장 객체·파일 + 14장 프로젝트 |

## 3. 1주차 구성

1주차는 이미 수업을 완료했으므로 새로 작성하지 않는다.

교재 1장에서 다룬 다음 내용이 기존 강의자료에 포함되어 있다.

- 컴퓨팅의 개념과 가치
- 컴퓨팅 사고의 의미
- 컴퓨팅 사고와 프로그래밍의 관계
- 하드웨어와 소프트웨어
- 프로그래밍 언어
- 저급언어와 고급언어
- 소스코드와 목적코드
- 컴파일러와 인터프리터
- 소프트웨어 개발 과정
- 문제 분석, 설계, 프로그래밍, 테스트, 사용, 유지보수
- 문제 분해, 패턴 인식, 일반화, 알고리즘의 개관

## 4. 2주차 구성: 문제 분해와 패턴 인식 + 파이썬 첫 실행

2주차부터 파이썬을 시작한다. 컴퓨팅 사고만 설명하고 끝내지 않고, 문제를 나눈 결과와 반복되는 패턴을 짧은 파이썬 코드로 표현한다.

### 4.1 이론 내용

#### 문제 분석

- 현상, 문제, 원인 가설, 해결책 구분
- 현재 상태와 목표 상태
- 입력과 출력
- 문제의 범위와 제약조건
- 사실, 가정, 의견 구분
- 해결 가능한 문제 문장 작성

#### 문제 분해

- 큰 문제를 작은 문제로 나누는 이유
- 해결할 수 있는 크기로 나누기
- 기능에 따른 분해
- 데이터에 따른 분해
- 시간 순서에 따른 분해
- 행위자에 따른 분해
- 하위 문제의 순차적 해결
- 하위 문제의 병렬적 해결
- 하위 결과의 결합
- 하위 문제 사이의 의존관계
- 누락, 중복, 지나치게 크거나 작은 분해 판별

#### 패턴 인식

- 분해된 문제 사이의 공통부분
- 반복되는 작업
- 반복되는 데이터 형식
- 조건에 따라 달라지는 결과
- 공통 계산 규칙
- 기존 해결 방법의 재사용
- 후보 패턴과 확정된 규칙 구분
- 반례 확인
- 상관관계와 인과관계의 기초

### 4.2 파이썬 기초 내용

교재 3장의 내용을 2주차 수준에 맞게 시작한다.

- 파이썬의 개념
- 파이썬이 사용되는 분야
- 대화형 실행과 코드 파일 실행의 차이
- 편집기에서 파일 저장 및 실행
- 프로그램은 위에서 아래로 실행된다는 원리
- `print()`
- 숫자와 문자열
- 따옴표
- 변수에 값 저장
- 변수값 출력
- 변수값 변경
- 기본 사칙연산
- 주석
- 실행 결과 확인
- 오류가 발생했다는 사실을 확인하는 방법
- `SyntaxError`와 `NameError`의 기초

`input()`, 형변환, 자료형의 자세한 설명은 간단히 소개할 수 있지만 3~4주차에서 체계적으로 다시 다룬다.

### 4.3 2주차 예제 코드 구성

#### 예제 1. 첫 번째 출력

```python
print("컴퓨팅 사고 수업을 시작합니다.")
print(2026)
print(3 + 4)
```

설명 항목:

- 문자열과 숫자의 차이
- 따옴표의 역할
- 괄호 안의 값을 출력한다는 의미
- 위에서 아래로 실행되는 순서

#### 예제 2. 학생식당 현황을 변수로 표현

```python
student_count = 42
window_count = 2
average_wait = 15

print("도착 학생 수:", student_count)
print("운영 창구 수:", window_count)
print("평균 대기시간:", average_wait)
```

설명 항목:

- 현실의 정보를 변수로 표현
- 변수 이름과 값
- 변수 이름을 읽기 쉽게 작성하는 이유
- 숫자를 직접 반복해서 쓰지 않고 변수에 저장하는 이유

#### 예제 3. 분해된 작은 계산 해결

```python
student_count = 42
window_count = 2

students_per_window = student_count / window_count

print("창구당 담당 학생 수:", students_per_window)
```

설명 항목:

- 전체 혼잡 문제 중 하나의 작은 계산
- 입력 역할의 변수
- 처리 역할의 계산식
- 출력 역할의 `print()`
- 입력-처리-출력 구조

#### 예제 4. 값 변경에 따른 결과 변화

```python
student_count = 42
window_count = 2
students_per_window = student_count / window_count
print(students_per_window)

window_count = 3
students_per_window = student_count / window_count
print(students_per_window)
```

설명 항목:

- 변수값 변경
- 같은 계산 구조의 재사용
- 창구 수 변화가 결과에 미치는 영향
- 문제 상황을 코드로 시험하는 간단한 시뮬레이션

#### 예제 5. 반복되는 코드에서 패턴 발견

```python
print("월요일 대기시간:", 14)
print("화요일 대기시간:", 12)
print("수요일 대기시간:", 15)
```

설명 항목:

- 동일한 출력 구조가 반복됨
- 바뀌는 부분과 바뀌지 않는 부분
- 반복되는 코드를 공통 절차로 만들 필요성
- 반복문은 아직 작성하지 않고 필요성만 이해

#### 예제 6. 간단한 오류 찾기

```python
student_count = 42
print(students_count)
```

설명 항목:

- 변수 이름이 서로 다름
- `NameError`가 발생하는 이유
- 오류가 발생한 줄 확인
- 변수 이름을 일관되게 작성

### 4.4 2주차 단계별 실습

2주차는 코드 실행 경험이 없는 학생도 충분히 따라올 수 있도록 단계별로 구성한다.

#### 실습 A. 그대로 입력하고 실행하기

- `print()`로 이름, 전공, 관심 분야 출력
- 숫자 계산 결과 출력
- 코드 실행 순서 확인
- 문자열의 따옴표를 제거했을 때 오류 관찰

#### 실습 B. 값만 변경하기

- 이용자 수 변경
- 창구 수 변경
- 대기시간 변경
- 실행 결과를 표에 기록

#### 실습 C. 변수 추가하기

다음 변수들을 직접 추가한다.

- `menu_count`
- `staff_count`
- `total_orders`
- `average_orders`

#### 실습 D. 빈칸 완성하기

```python
total_students = 60
team_count = 5

students_per_team = __________

print("팀당 학생 수:", __________)
```

#### 실습 E. 문제를 작은 계산으로 나누기

상황:

> 대학 축제에 생수 240병이 준비되어 있다. 운영 부스 6곳에 같은 수량으로 나누려고 한다.

학생이 작성할 내용:

1. 입력으로 필요한 값
2. 계산식
3. 출력할 결과
4. 파이썬 코드

#### 실습 F. 코드의 패턴 찾기

```python
monday = 14
tuesday = 12
wednesday = 15

print("월:", monday)
print("화:", tuesday)
print("수:", wednesday)
```

학생이 찾을 내용:

- 반복되는 부분
- 달라지는 부분
- 변수가 필요한 이유
- 나중에 자동화할 수 있는 부분

#### 실습 G. 오류 수정하기

다음 오류 유형을 각각 하나씩 제공한다.

- 닫는 따옴표 누락
- 닫는 괄호 누락
- 변수 이름 오타
- 문자열과 변수 혼동
- 계산식의 변수 누락

#### 실습 H. 독립 문제

다음 중 하나를 선택하여 10줄 이내의 프로그램을 작성한다.

- 동아리 회비를 인원수로 나누기
- 강의실 좌석을 여러 줄로 나누기
- 행사 간식을 팀별로 배분하기
- 하루 교통비로 일주일 교통비 계산하기
- 여러 대의 버스에 학생을 동일하게 배정하기

코드에는 다음 요소를 포함한다.

- 의미 있는 변수 세 개 이상
- 계산식 한 개 이상
- `print()` 두 번 이상
- 주석 한 줄 이상

### 4.5 2주차 수업 시간 배분

| 구간 | 시간 | 내용 |
|---|---:|---|
| 이론과 사례 | 35분 | 문제 분석, 문제 분해, 패턴 인식 |
| 파이썬 실행 시연 | 20분 | 실행환경, `print()`, 변수, 계산 |
| 따라 하기 | 25분 | 예제 1~4 실행 |
| 패턴·오류 활동 | 25분 | 예제 5~6 및 실습 F~G |
| 단계별 실습 | 45분 | 실습 A~E |
| 독립 문제 | 25분 | 실습 H |
| 결과 공유·정리 | 10분 | 서로 다른 해결 코드 비교 |

총 180분을 기준으로 하되 실제 수업 환경에 따라 조정한다.

## 11. 주차별 파일 구성

각 주차는 다음 세 파일로 작성한다.

| 파일 | 내용 |
|---|---|
| `weekXX-lecture.qmd` | 3,000자 이상의 이론, 새 사례, 표와 시각화, 예제 코드 |
| `weekXX-quiz.qmd` | 개념 확인, 실행 결과 예측, 오류 찾기, 짧은 서술 문제 |
| `weekXX-lab.qmd` | 따라 하기, 값 변경, 빈칸 완성, 오류 수정, 독립 구현 |

실습은 다음 순서로 난도를 올린다.

1. 예제 코드를 그대로 실행한다.
2. 입력값이나 변수값을 변경한다.
3. 코드 일부의 빈칸을 완성한다.
4. 잘못된 코드를 수정한다.
5. 비슷한 새 문제를 독립적으로 구현한다.
6. 실행 결과와 해결 방법을 설명한다.

## 12. 참고자료 사용 원칙

- 교재 강의교안은 반드시 먼저 확인한다.
- 교재의 장별 설명 항목을 체크리스트로 만든다.
- 교재의 문장과 예제는 복사하지 않는다.
- 파이썬 문법은 Python 공식 문서를 우선 확인한다.
- 컴퓨팅 사고 개념은 학술 논문과 교육 표준을 참고한다.
- 실제 통계가 아닌 데이터는 교육용 합성 데이터라고 표시한다.
- 본문에서 사용한 자료만 참고문헌에 포함한다.
- 확인하지 않은 수치나 단정적인 주장은 넣지 않는다.
