# 강의 이론 작성 규칙

이론파트(`weekXX_lecture.qmd`)를 작성·수정할 때 지키는 규칙을 모아 둔다.
주차별 내용 구성과 교재 개념 항목은 [강의작성_기준과_주차별_구성.md](강의작성_기준과_주차별_구성.md)를 따르고, 이 문서는 문장·표현·시각자료에 관한 규칙을 정한다.

## 1. 주차 간 상호 참조

- **다른 주차에서 자세히 다룬다는 예고를 본문에 쓰지 않는다.**
  - 금지 예: "선택과 반복은 5주차와 6주차에서 자세히 다룹니다.", "이 내용은 다음 주에 배웁니다."
  - 이유: 강의 일정과 순서가 바뀔 수 있고, 학생이 "지금은 몰라도 된다"며 학습을 미루게 된다.
- 아직 배우지 않은 문법이 등장하면 특정 주차를 지목하지 말고, "지금은 형태만 본다" 정도로만 안내한다.
- 지난 내용과의 연결(회상)은 허용한다. 예: "지난 시간에 다룬 문제 분해를 떠올려 봅니다." 앞 내용 회상은 되고, 뒤 내용 예고는 안 된다.

## 2. 시각자료(Mermaid)

- **Mermaid 그림은 적당한 크기로 그린다.** 화면을 벗어나거나 지나치게 커서 보기 힘들게 만들지 않는다.
- 지키는 방법
  - 한 그림에 노드를 너무 많이 넣지 않는다. 핵심 흐름만 담는다.
  - 라벨은 짧게 쓴다. 긴 문장은 `<br/>`로 줄바꿈하되 한 노드가 과도하게 커지지 않게 한다.
  - 한 개념에 그림 하나를 원칙으로 하고, 여러 개념을 한 그림에 몰아넣지 않는다.
  - 세로로 지나치게 길어지면 방향을 바꾸거나(`TD` ↔ `LR`) 그림을 나눈다.

## 3. 문체

- 종결체는 **경어체(~합니다)**로 통일한다.
- 시중 전문 교재의 서술 형태를 따른다. 여러 절이 자연스럽게 이어진 설명형 문장을 쓰고, 정의는 문장 속에서 담담하게 처리한다.
- 다음과 같은 인공적인 문장 습관을 피한다.
  - "A가 아니라 B"식 대비를 반복적으로 사용하는 것
  - 평범한 단어에 따옴표를 씌워 강조하는 것
  - 짧게 툭 끊는 한 줄 문장으로 극적 효과를 노리는 것
  - 연출된 장면·대사·말줄임표로 본문을 시작하는 것
  - "요점은 여기에 있습니다", "이제 답할 차례입니다"와 같은 자기연출 문구
- 도입은 구체적인 상황이나 사례로 시작하되, 대사가 아닌 차분한 평서문으로 쓴다.
- 메타 섹션(`학습목표`, `이 장을 마치면`, `배울 내용`, `다음 주차로 연결하기`)을 쓰지 않는다.
- 헤딩은 담백한 명사구로 쓴다.

## 4. 내용·근거

- 교재의 개념 항목은 빠짐없이 다루되, 교재의 문장·도표·예시는 복사하지 않고 새로 작성한다.
- 예시는 하나의 현실 사례(예: 대학축제)로 일관되게 연결한다.
- 실제 통계가 아닌 값은 교육용 합성 데이터임을 본문에 표시한다.
- 확인하지 않은 수치나 단정적인 주장은 넣지 않는다.

## 5. 참고문헌

- 참고문헌 목록은 본문에 두지 않고 `references/weekNN.md` 별도 파일에 보관한다.
- 본문에는 실제로 인용한 자료만 인라인 링크로 표시한다.
- 새 자료를 인용하면 `references/weekNN.md`와 `references/README.md` 목록을 함께 갱신한다.
